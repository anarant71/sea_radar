# Sea Radar

Учебное веб-приложение: карта пролива Дувр и суда на ней. Работает локально на компьютере преподавателя и не предназначено для навигации.

Задание заказчика — `docs/tasks/PROJECT_BRIEF.md`.

## Требования

Node.js 24, npm. Для тайлов OSM и настоящих позиций требуется интернет.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Настоящие позиции

Для загрузки снимка AISStream создайте в корне `.env.local` и задайте в нём `AISSTREAM_API_KEY` со своим ключом. Не добавляйте этот файл в Git и не отправляйте его другим людям. Без ключа демонстрационные суда доступны как обычно, а загрузка настоящих позиций покажет сообщение об ошибке.

Снимок собирается до 15 секунд и содержит не более 100 судов. Это неполная выборка сообщений, а не полный список судов района; настоящие позиции не обновляются между загрузками.

## Команды

```bash
npm run dev      # разработка
npm run build    # production-сборка
npm start        # запуск собранного приложения
npm test         # Playwright: node- и браузерные проверки
```

При первом запуске браузерных тестов установите Chromium:

```bash
npx playwright install chromium
```

Тайлы карты требуют интернет-соединения. Демонстрационная логика не требует ключа AISStream; приложение — учебное пособие, не средство реальной навигации.
