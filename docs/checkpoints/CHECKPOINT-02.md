## Что сделано

- На карте три демонстрационных судна `demo-1`…`demo-3`; маршруты по 10, 9 и 8 точек и скорость каждого судна заданы литералами в `src/config.ts`.
- Суда переходят к следующей точке маршрута раз в `DEMO_TICK_MS = 2000` мс; таймер один на все суда и снимается при уходе со страницы.
- Курс судна — начальный азимут отрезка по большому кругу: на старте к второй точке, далее от предыдущей точки к текущей (`bearingDeg` в `src/demo.ts`).
- Время сообщения проставляется в эффекте, то есть реальным временем браузера; до первого тика используется литерал `DEMO_START_TIME`, чтобы разметка сервера и браузера совпадали.
- Тем же тиком, которым судно приходит на последнюю точку, его скорость становится `0`; дальше судно возвращается прежней ссылкой и его время сообщения не тикает.
- Маршруты разной длины, поэтому суда останавливаются на разных тиках; когда пришли все, `stepDemo` возвращает прежнее состояние целиком.
- Карточка выбранного судна читается из того же `demo.vessels`, что и карта: выбор хранится идентификатором, а не копией судна.
- Установлен Playwright Test 1.63.0 — единственный тестовый раннер в проекте; один браузер, chromium.
- `playwright.config.ts`: `testDir: './tests'`, проект `chromium`, `webServer` с командой `npm run dev` и `reuseExistingServer: true`.
- Команда `npm test` в `package.json`; каталоги `test-results/` и `playwright-report/` внесены в `.gitignore`.
- Три браузерных теста выбора в `tests/selection.spec.ts`; суда и карточка ищутся только по `data-vessel-id` и `data-card-vessel-id`, запросы к тайлам прерываются в `beforeEach`.

## Проверки

- `npm run build` → успешно: TypeScript без ошибок, 3 статические страницы.
- `npm test` → passed 3, failed 0: три элемента с `data-vessel-id`; клик по судну открывает карточку с его `id`; повторный клик её не закрывает.
- `npm test` на пустом каталоге тестов (до написания тестов) → `No tests found`; с флагом `--pass-with-no-tests` → код выхода 0.
- Автостарт dev-сервера проверен временным тестом при свободном порте: Playwright поднял сервер, тест прошёл, после прогона `pgrep -f next-server` пусто. Временный тест удалён, в репозиторий не входит.
- Блокировка тайлов проверена временным тестом-зондом: 20 запросов к `tile.openstreetmap.org`, все 20 прерваны, других внешних запросов у страницы нет. Временный тест удалён, в репозиторий не входит.
- Утверждение теста 3 проверено на чувствительность: временный зонд удалил карточку из DOM, и то же `toBeVisible()` упало — значит закрытие карточки тест различает. Зонд удалён.
- Ручная проверка преподавателем, визуально, без автоматического теста: движение трёх судов по маршрутам.

## Что осталось за рамками

- Движение автоматически не проверяется: тесты выбора кликают по судну и читают карточку, но не ждут тиков и не сравнивают координаты во времени. Автоматическая проверка движения с управляемым временем — задача релиза R3.
- Остановка судна на последней точке и показ скорости `0 уз` в карточке в этом занятии не подтверждены: ни автоматическим тестом, ни отдельно зафиксированной ручной проверкой. В коде ветка есть (`vesselAt`, `speedKnots: arrived ? 0 : …`), на экране не наблюдалась.
- Обновление карточки выбранного судна вместе с картой автоматически не проверено; отдельной ручной проверки этого в занятии не зафиксировано.
- Требование B-06 «после hot reload в консоли один тик за интервал, не два» в этом занятии не проверялось — счётчик тиков в консоль не выводился.
- Нейтральный круглый значок и `data-icon="neutral"` не отрисовывались: `vesselAt` всегда вычисляет курс, судна с `courseDeg: null` в конфигурации нет.
- Ветка «Нет данных» на экране не появлялась: у всех трёх судов заполнены `name`, `speedKnots`, `courseDeg`.
- Атрибут `data-icon` тестами не проверяется — тесты находят суда по `data-vessel-id`.
- Тесты прогонялись только на chromium; других браузеров в конфигурации нет.
